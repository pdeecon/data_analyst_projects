## 🧮 Example DAX Measures

```DAX
Total Sales =
SUM(Sales[SalesAmount])
```

```DAX
Total Orders =
DISTINCTCOUNT(Sales[OrderID])
```

```DAX
Average Order Value =
DIVIDE(
    [Total Sales],
    [Total Orders],
    0
)
```

```DAX
Total Profit =
SUM(Sales[Profit])
```
